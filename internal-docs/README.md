# internal-docs

Internal, non-shipped notes for this gem — including the specs and plans the `superpowers` skills
generate (`internal-docs/specs/`, `internal-docs/plans/`). This directory is the location preference
the `brainstorming` / `writing-plans` skills defer to, and it's excluded from the packaged gem
(`spec.files` in the gemspec).

`docs/` is deliberately left free for a future user-facing site — keep internal drafts here, not there.
